# LRP - Laboratuvar Kaynak Planlama Sistemi

Bu proje, laboratuvarlardaki bilgisayarların ve bu bilgisayarlardan sorumlu öğrencilerin takip edilmesini sağlayan bir sistemdir.
.NET 8 Minimal APIs, SQLite ve Vanilla JavaScript kullanılarak geliştirilmiştir.

## Projeyi Çalıştırma
Projeyi çalıştırmak için projenin dizininde terminale `dotnet run` yazmanız yeterlidir.

**Test Hesapları:**
* **Admin:** admin / admin123
* **Öğrenci:** (Oluşturduğunuz öğrenci numarası) / 123
